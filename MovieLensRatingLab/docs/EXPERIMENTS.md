# 五个可证伪实验

把下面的假设作为起点，先写自己的预期。所有参数探索使用验证集。初版已公开当前 100K 尾段指标，后续在同一尾段的比较属于探索；独立确认需要额外未查看的数据及预先冻结的方案。下文“最终测试”指这份新保留的确认数据。不要把本文中的预期写成已经得到的结论。

每次实验保存：代码版本、数据校验值、时间边界、训练行数、参数、随机种子、主要指标、切片样本量与解释。跨实验的比较应固定数据划分和评分范围处理方式。

## 实验 1：正则化是否真的保护冷门电影？

**假设：** 对训练评分数较少的电影，适当的偏置收缩比近乎不收缩的估计有更低的验证 RMSE。

设计：固定模型类型与训练数据，只改变正则化强度。在训练数据上预先确定电影评分次数的分组边界，再比较各组的验证 RMSE、MAE 和样本量。未知电影单列，不与已见但冷门的电影混在一起。

证伪条件：候选收缩强度未在预先指定的冷门组改善主要指标，或改善很小且不稳定。最优正则化可能因切片而异，不能把某一组的结果推广到所有电影。

学习点：偏差与方差的权衡、收缩估计、小样本波动，以及分组定义的泄漏风险。

## 实验 2：增加用户偏置有多大实际收益？

**假设：** 在同一批验证评分上，`user_movie` 比 `movie` 的 RMSE 更低，且改进超过你预先设定的实际价值阈值。

设计：两种模型分别用验证集调参后锁定。使用同一批记录的配对预测比较误差；预先定义主要指标和差值方向。按用户聚类 bootstrap，抽中用户时取其全部记录，重复抽中的用户按次数计入。最终测试前记录实际价值阈值的理由，不能在看到差值后反推。

证伪条件：候选模型没有达到阈值，或区间不足以支持该幅度的改善。区间包含零意味着当前证据不能排除相反方向，不是两个模型等价的证明。

学习点：配对设计、效应大小、区间估计、统计不确定性与实际价值的区别。用户 bootstrap 不能自动处理电影之间的依赖、训练过程随机性或未来分布变化。

## 实验 3：总体指标是否掩盖冷启动问题？

**假设：** 候选模型相对基线的收益主要来自训练中已出现的用户和电影，对冷启动组的收益更小。

设计：只依据训练集 ID，将验证记录分成“用户电影均已见”“仅用户未见”“仅电影未见”“两者均未见”。报告各组评分数、用户数、RMSE、MAE 与模型差值。组太小时标注证据不足。再对已见电影按训练评分次数分层，检查整体收益是否被热门电影主导。

证伪条件：冷启动组有足够样本，且显示同等或更大的稳定改进。模型在未知 ID 上完全回退时，差值也可能由回退公式机械地决定，应先读实现再解释结果。

学习点：分层评价、模型适用范围、覆盖率，以及总体指标与群体表现的区别。冷启动身份由训练可见性决定，不能在读过未来数据后补全映射。

## 实验 4：矩阵分解是否值得它的复杂度？

**假设：** 自己实现的正则化矩阵分解，在时间验证下比最好的偏置基线有足够大的误差改善，且计算成本可以接受。

设计：保持时间切分不变，训练用户向量与电影向量；只用验证集选择维度、学习率、正则化和轮数。训练数据内建立 ID 映射，未知 ID 回退。固定候选搜索范围，保存随机种子，并对少量预先指定种子观察训练波动。记录运行时间、参数规模、RMSE 和 MAE。最终模型选择与主要比较冻结后，再使用测试集。

证伪条件：在预定预算内，复杂模型没有达到预定改善幅度，或改进不能抵偿计算成本与维护代价。失败也是有效结果；不要无限扩大搜索直到测试集出现优势。

学习点：优化、过拟合、模型选择、工程成本、重训练不确定性。评分矩阵分解的 RMSE 不能代替推荐排序的离线评价，更不能代替线上实验。

## 实验 5：模型优势能跨时间保持吗？

**假设：** 候选模型相对简单基线的优势，在多个相邻的未来验证窗口中方向一致。

设计：在开发数据范围内选择至少三个递增时间截点，使用扩展训练窗口；每次只训练截点之前的数据，并评价其后固定长度的时间窗口。同时间戳不跨边界。冻结参数，或在每个训练窗口内另设更早的内部验证集；不能根据当前评价窗口调参。新的独立确认数据不参与探索；当前已公开尾段不能再被称为未查看的保留区间。报告每个窗口的数据量、时间范围、新用户／新电影比例、电影流行度组成和误差差值。

证伪条件：优势方向在合理大小的窗口中反转，或仅在一个窗口出现。窗口间用户和电影可能重复，因此这些窗口不是独立重复实验；不能直接把各窗口当独立样本做显著性检验。

学习点：时间漂移、滚动验证、冷启动组成变化，以及“单次划分成绩好”与“跨时期稳定”的区别。时间戳是评分发生时间，不能据此还原观影时间、曝光时间或本地时段。

## 每份结论都应保留的边界

这些数据记录的是参与者主动提供的电影评分。没有曝光日志、未评分原因和随机分配机制，因此存在用户选择与评分选择偏差。分析能支持“在这一历史样本和评价规则下，预测已观察评分的误差如何变化”，不能支持“某因素导致用户更喜欢电影”或“这个系统会提高线上点击率”。

MovieLens 100K 是固定历史教学基准。样本规模、时期和参与人群限制了外推范围。先把方法和证据写扎实，再扩展到更大的数据、排序任务或真实实验。
